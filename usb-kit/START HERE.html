Snow Rider Controls

Version 0.7.3

Copy it onto your computer, then load it in Google Chrome. You can remove the USB after setup.

1. Copy the extension

  • Windows: double-click Setup - Windows.cmd on the USB. It copies the extension into a new folder in Downloads and opens that folder.
  • Mac: double-click Setup - Mac.command on the USB. It copies the extension into a new folder in Downloads and opens that folder.
  • Chromebook: open the Files app. Copy the whole Extension folder from the USB into My files > Downloads. Use a new folder name if a copy already exists.

If a helper cannot run, copying the Extension folder into Downloads yourself works on any of these computers. Keep all the files together.

2. Load it in Chrome

  1. Open Google Chrome and type chrome://extensions into the address bar.
  2. Turn on Developer mode at the top of that page. On Chromebook this is Chrome's extensions setting; you do not need to switch ChromeOS into Developer Mode.
  3. Click Load unpacked. Select the copied folder containing manifest.json.

The copy helpers copy files; this Chrome step installs the extension. Keep the copied folder in place after installation. A managed school or work computer may not allow unpacked extensions.

Chrome's official loading instructions

3. Play

Open Snow Rider 3D on Hooda Math and refresh the game if it was already open. The Snow Rider panel appears in the top-left. Drag its header to move it, or use its minus/plus button to minimize or expand it.

  • Invincibility: starts ON.
  • Super jump: starts ON. Choose jump strength from 1× to 20×, then use the Up arrow to jump.
  • Forward speed: select 1× to 10,000× normal speed using the slider, exact number or preset buttons.
  • Hold-to-boost: hold B or the Boost button for a temporary forward boost up to 10,000×. Release to return to your chosen forward speed.
  • Double jump: with flight OFF, press Up or Space to jump, then again in the air for one extra jump. Landing restores the extra jump.
  • Loadouts: open Loadouts to apply a preset or save up to eight named combinations of your options. Saving the same name updates it.
  • Live score: see your current game score at the top of the panel or in its minimized strip. It updates automatically.
  • Live speed and height: the panel shows speed in game units per second and height above your last grounded position. Height calibrates when grounded.
  • Flight: turn ON, hold Space to rise or Shift to descend, or hold the on-screen Rise/Descend buttons; release to hover.
  • Rise / descend speed: separately controls vertical flight speed.

Normal ride switches off movement boosts and protection. Reset defaults restores the starting options. Settings save automatically.

Shortcuts: Alt+S shows/hides the panel; Alt+F switches flight, Alt+J switches super jump, and Alt+I switches invincibility. Autopilot is experimental and is in the advanced section.

Nothing runs just because the USB is plugged in. These helpers copy local files only and need no administrator password. This extension targets Hooda Math's verified Snow Rider build; a changed game build can show “unsupported build”.
